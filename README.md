# EventHub: Event Management Website

A responsive event management website where users can browse events, search and filter them, view details, and register.

## Live Demo
https://your-username.github.io/event-website/

## Features
- Hero section and event cards
- Search and category filter
- Event details page with countdown timer
- Registration form with JavaScript validation
- Confirmation message on successful registration
- Dark/light mode
- Registrations saved in Local Storage

## Tech Stack
HTML5, CSS3, JavaScript (no frameworks)

## Folder Structure

## How to Run Locally
1. Clone the repo: `git clone https://github.com/DwipayanJena/event-website.git`
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.

## How It Works
- **events.js**: stores the event data.
- **main.js**: renders event cards, handles search, filters and dark mode.
- **event.js**: shows event details, runs the countdown, validates the form and saves registrations.
